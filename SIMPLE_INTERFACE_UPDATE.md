# BridgeVoice simple-interface update

- Main composer: one + menu (attach document, compare meaning, interpreter mode, response settings), microphone, send/stop. Advanced tools preserved behind the menu.
- Welcome shortcuts: Translate, Understand, Practice interpreting.
- Language selection: English, Pashto, Dari, Spanish. Selection updates the chat interface and common navigation; RTL for Pashto/Dari. Existing theme preference remains Light/Dark/System.
- Localized primary settings headings, interface/response language, and theme controls.

## Known gaps before production
Not every text string on secondary pages, legal content, error dialogs, demo workflows, and server responses is translated. These require complete localization review by native speakers. Pashto/Dari/Spanish speech recognition is not enabled by this update. AI requires valid server-side API credentials, provider availability, and end-to-end verification. This archive has not passed a build or browser test in this environment.
