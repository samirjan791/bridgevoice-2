# Competition demonstration · 110 seconds

Use fictional people and a live configured Meta connection. Rehearse each chosen browser/language before presenting. If unavailable, say so and switch to the explicitly labeled local proof/routing tests; never narrate them as live model output.

**0–15 seconds — Problem.** “An English-speaking receptionist and a Pashto-speaking customer need to understand an appointment instruction. BridgeVoice helps preserve the meaning, not just produce fluent words.” Open BridgeMode and show Person A English, Person B Pashto. Explain that this is one microphone with explicit turns.

**15–45 seconds — The bridge.** As Person A type or speak: “Your fictional appointment is on 12 November 2026 at 9 AM. Please bring your reference number AB-123.” Send and show the actual Meta-generated translation beside the original. Speak it only if a supported output voice exists. Select Person B and type “مننه” (thank you); show the direction switching and actual model response. Do not claim the Pashto mic is supported without prior verification.

**45–70 seconds — A critical misunderstanding.** Open the BridgeCall lab's controlled mismatch details. State: “This is a deliberately altered local test, not a model answer.” Show “Do not take more than 2 tablets in 24 hours” versus “Take 20 tablets in 24 hours.” BridgeProof flags the number/negation and asks human review. Explain that high-risk content never gets a safety certificate.

**70–90 seconds — Resolution.** Prepare the human handoff summary. “This keeps the original intact and packages the issue for a qualified reviewer. It has not contacted an interpreter.” Optionally request separate Meta semantic review if latency permits; explain that model agreement is not proof.

**90–110 seconds — Future, honestly.** Start the labeled simulated call, acknowledge both fictional consents and route a sample payload from A to B only. “This tests routing rules locally. Real telephone translation is disabled until our isolated audio gateway and two-phone tests are verified.” End with: “Meta powers the translation and reasoning. BridgeVoice makes potential misunderstandings easier to see and resolve.”

Backup: show the local proof tests and test report if network service fails; explicitly disclose the failed live attempt. Do not use actual patient information or describe this as certified medical interpretation.
