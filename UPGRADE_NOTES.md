# BridgeVoice four-language + appearance update

- Added US Spanish interface strings and language selection.
- Added server request validation for Spanish and optional Spanish glossary terminology.
- Added Light / Dark / System appearance preferences. System theme responds to OS appearance changes.
- Added a Languages shortcut in the navigation sidebar.

## Limitations

Live AI translation requires a correctly configured, compatible Meta endpoint and server-side credentials. Offline guided mode is not a translation engine. Speech recognition remains English-only in this build; Spanish and other languages must be typed for now. Document extraction varies by file format. No API connectivity, deployment, or real-world multilingual accuracy has been verified.
