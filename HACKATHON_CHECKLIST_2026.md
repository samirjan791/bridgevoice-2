# BridgeVoice — Meta Global AI Developer Hackathon checklist (October 24, 2026)

## Confirmed from the official event page

- Track: **Indie developer** (individual builders and students); judging considers **creativity, technical ambition, and whether the project works**.
- Project theme: **Build for Your World** — solve a problem the builder knows firsthand.
- Hackathon: October 26–November 4, 2026.
- Submission deadline: **November 4, 2026 at 9:00 PM Eastern Time** (8:00 PM Central Standard Time in San Antonio on that date).
- Meta tooling options include Muse Spark series, Muse Image, SAM 3.1 via Meta Model API, Meta open-weights models, and Muse Code. Plan to demonstrate substantive Meta-model use.
- **Official Rules were not yet published on the event page as of October 24.** Selected participants must review and accept them. Do not assume this checklist is exhaustive.
- Source: https://dev.meta.ai/events/global-hackathon

## Required work before calling the project submission-ready

- [ ] Read and accept the final official rules when published; check any team, intellectual-property, eligibility, and submission requirements.
- [ ] Confirm the approved Indie track and final submission portal from your acceptance communication.
- [ ] Obtain valid Meta Model API credentials and confirm the available model and endpoint.
- [ ] Configure credentials only on the server (never NEXT_PUBLIC or browser code); ensure API requests work end to end.
- [ ] Verify live multilingual answers for English, Pashto, Dari, Spanish, with native-speaker checks for high-stakes language.
- [ ] Test uploads, error messages, microphone permissions, RTL layout, language switching, Light/Dark/System, keyboard and mobile browsers.
- [ ] Ensure simulated cases remain clearly labeled in Demo Studio; never claim fake scenarios are real clients.
- [ ] Test privacy, request limits, data handling, and clear human-review notices for medical/legal contexts.
- [ ] Deploy a public HTTPS site and test from an unrelated device and network.
- [ ] Prepare demo video, project summary, screenshots and any additional materials specified by final rules.
- [ ] Submit before the official deadline; do not rely on last-minute deployment.
